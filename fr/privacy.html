POLITIQUE DE CONFIDENTIALITÉ

Vos données restent les vôtres.

Dernière mise à jour : juin 2026

En bref

  • Nurtura est local d'abord. Vos enregistrements, photos et profils enfants sont stockés par défaut sur votre appareil.
  • Vous pouvez utiliser l'app sans créer de compte.
  • La synchronisation cloud optionnelle (via Supabase) garde vos données accessibles sur tous vos appareils lorsque vous vous connectez avec un email.
  • Nous ne vendons pas vos données. Nous n'utilisons pas d'analytics tiers sur les données parent ou bébé.
  • Vous pouvez tout supprimer en désinstallant l'app.

Ce que nous collectons

Uniquement ce qui est nécessaire au fonctionnement de l'app :

  • Profil de l'enfant (prénom, date de naissance, date prévue, étape de vie) — saisi par vous, stocké localement.
  • Logs quotidiens (sommeil, pleurs, attachement, appétit ; notes optionnelles ; signaux QCM optionnels) — saisis par vous, stockés localement.
  • Souvenirs (photos, légendes, étiquettes de jalons optionnelles) — fichiers image stockés localement.
  • Email du compte — uniquement si vous activez la synchronisation cloud.
  • Statut d'achat — géré par RevenueCat (notre processeur d'achats) et Apple, lié à votre identifiant Apple.

Ce que nous ne collectons pas

  • Pas d'historique de navigation, d'identifiants publicitaires ou d'empreintes d'appareil.
  • Aucun SDK d'analytics tiers dans l'app destinée aux parents.
  • Aucune donnée de localisation.
  • Pas d'accès au microphone ni aux contacts.

Synchronisation cloud (optionnelle)

Lorsque vous vous connectez avec un email, le profil de l'enfant, les logs et les analyses sont répliqués sur Supabase pour être disponibles sur tous vos appareils. Les photos et souvenirs restent uniquement en local.

Vous pouvez désactiver la synchronisation à tout moment dans Profil → Synchronisation cloud.

Partage avec le partenaire

Si vous invitez un partenaire avec un code de partage, il obtient un accès en lecture à la chronologie, aux logs récents et aux insights de votre enfant. Le code est à usage unique et peut être révoqué à tout moment. Aucune donnée du partenaire ne quitte les serveurs de Nurtura.

Permissions demandées

  • Notifications — pour envoyer le rappel quotidien optionnel. Vous le contrôlez dans Profil ou dans les Réglages iOS.
  • Photothèque — uniquement quand vous touchez "Ajouter un souvenir" → "Choisir depuis la bibliothèque". Nous n'y accédons pas autrement.
  • Appareil photo — uniquement quand vous touchez "Ajouter un souvenir" → "Prendre une photo".

Vos droits

Vous pouvez demander une copie de vos données ou la suppression de vos données stockées dans le cloud en écrivant à support@nurtura.app. Les données locales peuvent être supprimées à tout moment en désinstallant l'app.

Contact

Questions, demandes ou préoccupations : support@nurtura.app

Nurtura n'est pas un dispositif médical et ne diagnostique, ne traite ni ne remplace un avis professionnel.
